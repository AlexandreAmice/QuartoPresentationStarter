# Showcase Deck

Optional reference deck that demonstrates richer reveal.js + Quarto capabilities.

Includes examples of:
- fragments and incremental reveals
- auto-animate
- vertical slide stacks
- mermaid diagrams
- media embeds
- theorem/callout layout patterns
- executable code examples

- Canonical deck: `presentation.qmd`
- Edit mode deck: `presentation.edit.qmd`
- Sections: `sections/*.qmd`
- Deck-local css: `showcase.css`

Render explicitly:

```bash
quarto render presentations/showcase/presentation.qmd
```
